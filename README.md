# linklist-cpp-
C++ 单链表完整实现（考研数据结构基础代码）

## 项目介绍
本仓库是使用C++实现的基础单向链表，包含链表全套核心操作，适用于数据结构入门、考研算法复习。

## 实现功能
1. 尾插法创建链表
2. 遍历打印所有节点
3. 指定位置插入元素
4. 指定位置删除元素
5. 根据数值查找节点位置
6. 释放链表内存，避免内存泄漏

## 文件说明
- linklist.cpp：完整无注释单链表源代码
- README.md：项目说明文档
